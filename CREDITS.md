# Credits & Acknowledgements 🌟

`starlight-to-md` is an open-source project created to bridge documentation sites and AI coding agents. We gratefully acknowledge the following projects and authors whose work made this possible:

---

### Conceptual Inspiration

- **[deepwiki-md](https://github.com/zxmfke/deepwiki-md-chrome-extension)**  
  Special thanks to the creators of `deepwiki-md`, whose extension architecture inspired the concept of bringing instant, clean documentation extraction to browser extensions for AI agents.

---

### Core Frameworks & Ecosystem

- **[Starlight](https://github.com/withastro/starlight)** ([docs](https://starlight.astro.build/))  
  Created by the Astro Technology Company and open-source contributors. Starlight is the documentation framework for which this extractor is customized, supporting Expressive Code, custom asides, sidebar trees, and tabs.

---

### Open Source Libraries

- **[Turndown](https://github.com/mixmark-io/turndown)**  
  Created by [Dom Christie](https://github.com/domchristie) and maintained under the MIT License. Turndown powers the robust HTML-to-Markdown conversion engine.

- **[JSZip](https://github.com/Stuk/jszip)**  
  Created by [Stuart Knightley](https://github.com/Stuk) and contributors under the MIT / GPLv3 dual license. JSZip provides the client-side zip packaging for categorized documentation archives.

- **[esbuild](https://esbuild.github.io/)**  
  Created by [Evan Wallace](https://github.com/evanw) under the MIT License. Powers the lightning-fast IIFE extension bundling pipeline.

- **[Playwright](https://playwright.dev/)**  
  Created by Microsoft under the Apache 2.0 License. Powers the end-to-end testing suite validating live extension loading and multi-site extraction.

---

### Community & Contributors

Thank you to everyone who tests, reports issues, and submits pull requests to make `starlight-to-md` better for developer and AI workflows worldwide.
